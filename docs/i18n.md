# Sistema i18n

Internacionalización artesanal sin librerías externas.

## Estructura de Rutas

```
/           → Inglés (default, sin prefijo)
/es/        → Español

/about      → About EN
/es/about   → About ES

/work       → Work EN
/es/work    → Work ES
```

## Archivos

### `src/i18n/ui.ts`

Diccionario central con todas las cadenas de texto del proyecto.

**Exporta:**
- `languages` — `{ en: 'EN', es: 'ES' }`
- `defaultLang` — `'en'`
- `navItems` — array de `{ id, href }` para la Navbar
- `ui` — objeto con todos los strings agrupados por idioma

**Claves disponibles:**

```
nav.work          nav.about         nav.journal
nav.contact       nav.resume

hero.descriptor   hero.cta.work     hero.cta.contact

about.eyebrow     about.heading     about.p1     about.p2

work.eyebrow      work.heading

journal.eyebrow   journal.heading

contact.eyebrow   contact.heading   contact.p1   contact.cta

footer.copy
```

### `src/i18n/utils.ts`

Helpers para usar en cualquier componente o página de Astro.

```ts
// Detecta el idioma desde la URL
getLangFromUrl(url: URL): Lang

// Devuelve una función t(key) para el idioma dado
useTranslations(lang: Lang): (key) => string

// Construye una ruta con el prefijo de idioma correcto
getLocalePath(path: string, lang: Lang): string
// → getLocalePath('/about', 'es')  →  '/es/about'
// → getLocalePath('/about', 'en')  →  '/about'

// Construye la ruta del idioma alternativo (para el toggle EN/ES)
getAlternateLangPath(pathname: string): { lang: Lang; href: string }
```

## Uso en una página Astro

```astro
---
import { getLangFromUrl, useTranslations } from '../i18n/utils';

const lang = getLangFromUrl(Astro.url);
const t = useTranslations(lang);
---

<h1>{t('hero.descriptor')}</h1>
<p>{t('about.p1')}</p>
```

## Páginas ES

Las páginas en español son copias exactas de las EN con dos diferencias:
1. Imports usan `../../` en vez de `../` (nivel de carpeta extra)
2. Los `href` de CTAs apuntan a `/es/ruta` en vez de `/ruta`

El idioma se detecta automáticamente en runtime via `getLangFromUrl(Astro.url)`,
por lo que el mismo componente renderiza en el idioma correcto sin lógica adicional.

## Agregar un nuevo string

1. Añadir la clave en `ui.ts` bajo `en:` y `es:`
2. Usar `t('nueva.clave')` en la página/componente
3. El fallback al inglés es automático si falta la traducción en ES
